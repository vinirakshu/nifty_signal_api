What do these terms mean?
TWAP / VWAP
Average Nifty price so far today. Above it = buyers in control.
EMA 9 / 21
Short and medium moving averages. 9 above 21 = uptrend.
CPR
Central pivot range from yesterday's prices. Above it = bullish day, below = bearish, inside = sideways.
PCR
Put-call ratio of open interest. High (above 1.2) = more put sellers = support below; low (below 0.8) = more call sellers = resistance above.
Pivot R1–R3 / S1–S3
Resistance and support levels worked out from yesterday's high, low and close.
OI wall
Strike with the most open option contracts; it often acts as a barrier.
Max pain
Strike where option buyers as a group would lose the most at expiry.
ATR
Average size of a 5-minute candle; used to size the stop-loss.
Dots ●
How many different methods point to the same level. More dots = stronger level.
